## Isolation discoveries affecting interpretation

- CTest registers 211 tests, but 103 shell-backed entries hard-code
  `BUILD="$ROOT/build"`; 15 honor `DAW_BUILD_DIR`; 93 use a compiled binary,
  Cargo, or another entry point. Therefore an independently named CTest build
  directory does not imply independent artifacts.
- 103 scripts prefer `ui/target/debug/daw-cli` over release when debug exists.
  That debug binary was rebuilt before any baseline suite.
- The tracked `ui-web/node_modules` path is an absolute symlink into the
  frontend-owned worktree. Web dependency tests are not attributable to this
  checkout until AE-P0.1 removes it and creates a local ignored install.
- Existing scripts have shared plugin-cache, audio-device, evidence-directory,
  and runtime-resource behavior. A full sweep is therefore serialized against
  the frontend owner's active gate rather than overlapped.
- Current tests do not emit a machine-readable source/artifact provenance
  manifest. The hashes in this record are manually captured evidence, not an
  existing fail-closed product capability.
