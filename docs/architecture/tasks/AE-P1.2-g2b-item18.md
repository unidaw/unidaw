## Non-goals

- No product source is changed by this packet.
- No SetBypass host-applied acknowledgement is added; successful full-frame transmission on the ordered control stream remains the defined bypass-staging boundary.
- No global mirrorOnly gate may silence unrelated tracks.
- Authored TrackChain and Device values remain the document/UI authority; execution modules may not consume them after migration.
- Compact host indexes, pooled patcher node ids, and owner aliases are plan-local derived values and are not persisted as authored identities.
- The ReplayComplete payload and mailbox acknowledgement meaning change without moving bytes, so kControlVersion advances 14 to 15 and kShmVersion advances 41 to 42 in C++, Rust, and SHM_LAYOUT.md.
- Non-execution TrackStateSnapshot fields remain outside this packet; chainDevices and routing are removed rather than retained as second execution authorities.
- Schema 1-5 concrete target_plugin_index values are not guessed from the current machine; only the all-target sentinel is directly migratable, while concrete legacy lanes retain their events and original compact number in an explicitly disabled tagged target.
- Existing narrow device-id carriers do not widen: the exact 0x7FFF stable-id ceiling makes every 15-bit and 16-bit carrier lossless, and every narrowing boundary validates before conversion without masking or wrapping.
- Transient event-ring occupancy never authorizes a drain ProcessBlock; only an already-issued exactly correlated in-flight request may complete before the identical session block is retried.
- Device ids are globally unique within a project, not merely within a track; schema-6 persists one project watermark and legacy migration rewrites every track-scoped reference through an explicit {trackId, oldDeviceId} map.
- A post-reservation control-frame failure is not retried as partial success: it poisons the session dispatch, accepts no output or transport advance, and quarantines every participant before future playback.
- Every Track routing edge has exactly one block of delay; cycles are legal delayed feedback, and fan-in is reduced in ascending source track id, source bus, and channel order.
- Legacy state blobs and parameter manifests are independent optional artifacts read through the same {trackId, oldDeviceId} migration map as the document; present corrupt files fail closed, schema-6 documents reference an immutable digest inventory, and loads/modules never infer provenance from ambient canonical-looking filenames.
